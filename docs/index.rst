Welcome to Fluvial
==========================

``fluvial`` is an open source pipeline framework for generation, execution, and analysis of free energy calculations using the `Open Free Energy <https://openfree.energy/>`_ stack. It enables declarative pipeline composition through an extensible plugin system, delivering a tunable plug-and-play experience for inferencing cofolded ligand-protein systems all the way to running free energy calculations using free and open source tooling.

``fluvial`` is released under the MIT license and developed at its `GitHub repository <https://github.com/omsf/fluvial>`_.
