Getting started
===============

OpenPlaceHolder is designed to provide a declaratively composed pipeline for generating the complex structures for a congeneric series, executing physics-based simulations, and returning binding free energy estimates. 

As an example, the following configuration file defines a full pipeline for a congeneric series of four ligands bound to `TYK2 <https://github.com/OpenFreeEnergy/IndustryBenchmarks2024/tree/main>`_ using structures generated by OpenFold-3. *OpenPlaceHolder is capable of executing its full pipeline given only this file*. Each stage then hands its output to the next:

- These structures are **validated** using `PoseBusters <https://github.com/maabuu/posebusters>`_ and a simple RDKit stereochemistry validator. Structures that do not pass validation are simply filtered out of the available pool of structures.

- A **selector** determines the minimal set of structures that will represent the congeneric series (1 structure per protein-ligand complex), in this case optimizing on volume and interaction fingerprint overlaps.

- The selected structures are then **transformed** such that they all share the same consistent set of system parameters (e.g. protonation states).

- A **mapper** plans the alchemical network and the **simulator** runs every transformation in that network.

- The **analyzer** uses the simulator outputs and translated them into binding free energy estimates and reports network level diagnostics.

   [generation.generator]
   implementation = "openplaceholder.impl.generator.openfold3:OpenFold3Generator"
   run_openfold_path = "run_openfold"  # must exist in path
   n_diffusion_samples = 5
   generate_n_seeds = 5
   generator_directory = "/tmp/openfold_3_generator/tyk2"
   sequence = "MGSPASDPTVFHKRYLKKIRDLGEGHFGKVSLYCYDPTNDGTGEMVAVKALKADAGPQHRSGWKQEIDILRTLYHEHIIKYKGCCEDAGAASLQLVMEYVPLGSLRDYLPRHSIGLAQLLLFAQQICEGMAYLHAQHYIHRNLAARNVLLDNDRLVKIGDFGLAKAVPEGHEYYRVREDGDSPVFWYAPECLKEYKFYYASDVWSFGVTLYELLTHCDSSQSPPTKFLELIGIAQGQMTVLRLTELLERGERLPRPDKCPAEVYHLMKNCWETEASFRPTFENLIPILKTVHEKYRHHHHHH"

   [generation.generator.ligands]
   ejm_31 = 'CC(=O)Nc1cc(NC(=O)c2c(Cl)cccc2Cl)ccn1'
   ejm_42 = 'CCC(=O)Nc1cc(NC(=O)c2c(Cl)cccc2Cl)ccn1'
   ejm_43 = 'CC(C)C(=O)Nc1cc(NC(=O)c2c(Cl)cccc2Cl)ccn1'
   ejm_44 = 'CC(C)(C)C(=O)Nc1cc(NC(=O)c2c(Cl)cccc2Cl)ccn1'

   # per-structure physical/chemical validation. each must pass.
   # multiple validators can be stacked.
   [[selection.validators]]
   implementation = "openplaceholder.impl.validators:PosebustersValidator"

   [[selection.validators]]
   implementation = "openplaceholder.impl.validators:StereoValidator"

   [[selection.normalizers]]
   implementation = "openplaceholder.impl.normalizers:BindingSiteAligner"
   radius = 6.0
   
   [selection.selector]
   implementation = "openplaceholder.impl.selector.mpo:MPOSelector"

   [selection.selector.objectives]
   VolumeOverlapObjective = { weight = 1.0 }
   IFPSimilarityObjective = { weight = 1.0 }

   [[assembly.transformations]]
   implementation = "openplaceholder.impl.transformations:MaxVolumeSiteSubstitutionTransformation"

   [[assembly.transformations]]
   implementation = "openplaceholder.impl.transformations:HeavyAtomAdditionTransformation"

   [[assembly.transformations]]
   implementation = "openplaceholder.impl.transformations:ComplexProtonationTransformation"
   ph = 7.0

   [assembly.mapping]
   implementation = "openplaceholder.impl.mappers:KartografMapper"

   [simulation.simulator]
   implementation = "openplaceholder.impl.simulators:OpenFESimulator"
   simulation_directory = "/tmp/openfe_simulator/simulations"
   production_length_ns = 5.0

   [analysis.analyzer]
   implementation = "openplaceholder.impl.analyzers:CinnabarAnalyzer"
