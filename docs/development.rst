Development
===========

Automated testing and code quality
----------------------------------

Testing is performed with `pytest <https://pytest.org/>`_, targeting the ``openplaceholder.tests`` subpackage.

The correctness of ``openplaceholder`` depends heavily on the `Python static typing <https://typing.python.org/en/latest/>`_, which is strictly checked with `mypy <https://mypy.readthedocs.io/en/stable/>`_.

Code style
----------

All contributed code must be formatted with `Black <https://black.readthedocs.io/en/stable/>`_ and imports should be sorted with `isort <https://isort.readthedocs.io/en/latest/>`_.
